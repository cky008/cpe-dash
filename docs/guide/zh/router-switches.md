右上角的「控制」抽屉里，除了[锁频与锁小区](locking.md)，还有一组路由器开关。它们和路由器官方网页里的同名设置是同一份，改一边另一边也会变。每次打开或关闭都会先弹出确认，说明会有什么影响。

> [!NOTE]
> 抽屉不会定时读取这些设置。打开抽屉后点「读取路由器配置」，看到的才是路由器当前的状态。

## 安全开关

<a id="upnp"></a>

### UPnP

UPnP（通用即插即用）让家里的设备自动请求路由器打开端口，外面的人就能连进来。联机游戏、BT 下载、部分视频通话软件会用到它 [[华为：如何开启 UPnP](https://consumer.huawei.com/en/support/content/en-us00275342/)]。

- **开着**：方便，但任何一台设备（包括被入侵的智能设备）都可以自己在路由器上开端口。
- **关着**：更安全；少数需要外部连入的应用可能连不上。
- 建议：用不到就关闭。注意：大多数家用 5G 网络在运营商那里还有一层地址转换，即使开了 UPnP，外部也未必连得进来。

<a id="dmz"></a>

### DMZ 主机

DMZ 主机会把所有没有被别的规则处理的外部连接，统统转给你指定的那台设备 [[Fortinet: What is a DMZ network?](https://www.fortinet.com/resources/cyberglossary/what-is-dmz)] [[华为：如何设置 DMZ 主机](https://consumer.huawei.com/en/support/content/en-us15806289/)]。

> [!CAUTION]
> 开启后，那台设备相当于直接暴露在公网上。只在你清楚后果、且那台设备自己有防火墙时使用；用完就关。

<a id="firewall"></a>

### 防火墙总开关、IP 过滤、URL 过滤

- **防火墙总开关**：路由器的基础防护，挡掉外部主动发来的连接。保持开启。
- **IP 过滤**、**URL 过滤**：按你在路由器官方网页里设置的规则，挡掉某些地址或网站。烽燧只负责开关，规则本身在官方网页里编辑。

<a id="wan-ping"></a>

### WAN 口 Ping

决定路由器要不要回应来自公网的 Ping（ICMP 回显请求）[[RFC 792](https://www.rfc-editor.org/rfc/rfc792)]。屏蔽后，网上的扫描器更难发现你的路由器在线，对正常上网没有影响。建议屏蔽。

<a id="fw-mac"></a>

### MAC 过滤（防火墙）

这是路由器防火墙里的 MAC 名单，和[设备与上网管理](devices.md#mac-filter)里的 Wi-Fi MAC 过滤不是一回事：它对有线和无线设备都生效 [[华为：路由器如何设置 MAC 地址过滤](https://consumer.huawei.com/cn/support/content/zh-cn15933072/)]。

> [!WARNING]
> 如果名单是「只允许」模式，名单外的设备都会断网，可能包括运行烽燧的那台机器。

## Wi-Fi

<a id="mlo"></a>

### MLO 多链路

MLO（多链路操作）是 Wi-Fi 7 的功能：支持它的设备可以同时用 2.4 GHz、5 GHz 等多个频段和路由器通信，速度更快、延迟更低、更不容易断 [[Wi-Fi Alliance: Wi-Fi CERTIFIED 7](https://www.wi-fi.org/news-events/newsroom/wi-fi-alliance-introduces-wi-fi-certified-7)] [[IEEE 802.11be](https://standards.ieee.org/ieee/802.11be/7516/)]。

- 只有 Wi-Fi 7 设备能用上；老设备照常连接。
- 个别老设备在 MLO 开启时连不上或不稳定，遇到时可以先关掉试试。

<a id="dbho"></a>

### 双频优选

把 2.4 GHz 和 5 GHz 合成一个 Wi-Fi 名称，由路由器自动把设备引导到更合适的频段，通常优先 5 GHz [[华为：设置 5 GHz 优先](https://consumer.huawei.com/en/support/content/en-us00746587/)]。

- 开着：只有一个 Wi-Fi 名称，省心。
- 关着：2.4 GHz 和 5 GHz 分成两个名称，适合只支持 2.4 GHz 的智能家居设备配网。

## 天线

<a id="antenna"></a>

部分型号带外置天线接口。这里可以选「自动」「内置」或「外置」，并显示每个接口有没有接上天线。没有接外置天线时请保持「自动」或「内置」；一般情况下内置天线已经够用 [[华为：外置天线接口的作用](https://consumer.huawei.com/en/support/content/en-us00728109/)]。

## 移动数据、重拨和重启

<a id="mobile-data"></a>

- **移动数据**：关闭后路由器不再通过 SIM 卡上网，局域网照常工作。
- **重拨蜂窝数据**：断开再重新连接运营商网络，相当于手机开关一次飞行模式，几秒到几十秒后恢复。上网卡住时先试这个。
- **重启路由器**：整台路由器重启，家里会断网一两分钟。需要输入确认词。

烽燧的自愈功能只会自动重拨，从不自动重启路由器，见[锁频与锁小区](locking.md#self-heal)。

## 蜂窝设置

控制抽屉的「蜂窝设置」一节管的是路由器怎么连运营商：用哪种网络、哪个运营商、哪张 SIM 卡、哪个接入点。每台路由器只显示它自己有的那几项，哪个型号有哪几项见[支持的设备](supported-devices.md)。目前这些设置都还没有在真机上验证过，属于[实验性写入](other-routers.md)：每项只发一次，发完在同一次连接里读回来核对，可以在「设置 → 设备」里逐项关闭。

> [!NOTE]
> 改了网络制式、手动选了运营商、切了 SIM 卡槽或改了接入点之后，如果断网超过 3 分钟，烽燧会把这一项改回原来的值，并发一条告警。原来的值读不到的，烽燧不会乱改，会在告警里说明。关闭移动数据和打开飞行模式是你有意断网，烽燧不会替你改回去。

<a id="network-mode"></a>

### 网络制式

决定路由器可以用哪几代网络：自动、只用 5G、只用 4G、只用 3G 等，可选的制式因路由器而异 [[3GPP TS 23.122](https://www.3gpp.org/DynaReport/23122.htm)]。只用 5G（SA）在没有 5G 独立组网覆盖的地方会没有信号；拿不准就用「自动」。

<a id="operator-select"></a>

### 手动选网

平时路由器自己选运营商。手动选网是先让路由器搜一遍附近的网络，再让它只注册到你选的那一个 [[3GPP TS 23.122](https://www.3gpp.org/DynaReport/23122.htm)]。

- 搜索要一到三分钟，这段时间移动网络是断开的。
- 列表里的名字是运营商自己写的；标着「不可用」的是这张 SIM 卡不能用的网络。
- 选定之后路由器不再自己换运营商。选的网络用不了时会断网，3 分钟后烽燧把它改回自动选择。
- 中兴的路由器只能从最近一次搜索的结果里选，所以先搜索再选。

### SIM 卡槽

有内置卡（eSIM）或多个卡槽的路由器，可以在这里换用另一张卡。换卡后路由器要重新联网，大约一分钟。卡槽的说法见[控制台](dashboard.md#esim)。

### SIM PIN

可以做两件事：SIM 卡在等 PIN 时输入 PIN；打开或关闭「开机要 PIN」。PIN 的说明见[控制台](dashboard.md#sim-pin)。

- 烽燧每次只发一次，路由器说不对就停，不会换一个再试。
- 只有路由器报告了剩余次数、并且还剩不止一次时才能发；确认框里会写明还剩几次。读不到次数或只剩一次时，请到路由器自己的管理页处理。
- PUK 连续输错十次，SIM 卡就永久作废，所以烽燧不提供输入 PUK，也不提供修改 PIN。
- PIN 只发给路由器，烽燧不保存，也不写进任何记录。

### 飞行模式

打开后路由器关掉蜂窝无线电、断开移动网络，局域网和 Wi-Fi 照常；要回到烽燧里关掉。如果你是通过这条移动网络远程访问烽燧的，打开后就连不上了。飞行模式的说明见[控制台](dashboard.md#airplane-mode)。

### 数据漫游

决定连着别的运营商的网络时用不用流量。漫游的流量可能另外收费；如果正在漫游时关掉它，会马上断网。漫游的说明见[控制台](dashboard.md#roaming)。

<a id="apn"></a>

### 接入点（APN）

APN（接入点名称）告诉运营商这张卡走哪条线路上网 [[3GPP TS 23.003](https://www.3gpp.org/DynaReport/23003.htm)]。大多数 SIM 卡用「自动」就行；物联网卡、专网卡要按运营商给的名称手动填。

- 填错了会断网，3 分钟后烽燧改回原来的接入点。
- 在中兴的路由器上，烽燧只写自己的那一份配置（名为 `FengSui`），路由器原有的配置不动；改回去时把原来那份重新设为默认。
- 在 OpenWrt 上只能填名称和地址类型，不能填用户名和密码。
- 接入点的名称、用户名和密码不会出现在烽燧的任何记录里。

<a id="data-limit"></a>

### 流量上限与流量统计

这是路由器自己记的月流量上限，和烽燧的[流量告警](notifications.md)是两回事：到了你设的提醒比例，路由器会按它自己的方式提示。「清零流量统计」把路由器自己记的流量归零，不能撤销；烽燧里的流量图表不受影响。

<a id="ussd"></a>

### USSD

USSD 是发给运营商的短指令，比如 `*100#`，用来查余额、查套餐或办理业务 [[3GPP TS 22.090](https://www.3gpp.org/DynaReport/22090.htm)]。

- 有的指令会办理业务或扣费，发之前想清楚。
- 运营商有时会回一个菜单等你回复；可以接着回复，或者结束会话。
- 应答是运营商自己写的内容。指令和应答都只显示给你看，烽燧不保存，也不写进任何记录。
